# Chat Dragons Mod

A Minecraft Java mod for NeoForge 1.21.1 featuring dragons from our shapes.inc chat — saddles, flight, and lore included.

## Status

Scaffold stage. First milestone: NeoForge 1.21.1 mod skeleton that builds cleanly and launches with one test dragon.
